2. Typography

Headings use Poppins (geometric, friendly, distinctive at large sizes). Body and UI text use Inter for legibility in forms and dense content. Both fall back to the system sans-serif stack. Sizes use clamp() so headings scale fluidly between breakpoints instead of jumping.

4. Breakpoints & responsive rules

Two breakpoints, chosen where the content needs more columns — not for specific devices. All styles are written mobile-first; media queries only add complexity as width increases.

Mobile (default)< 768px390 × 844Single columnHamburger menu; stacked hero; 1-column card grids; full-width buttons and form fields; segmented progress bar; horizontally scrolling date strip and dashboard tabs
Tablet≥ 768px768 × 1024Two column where usefulHorizontal nav + header CTA; 2-column card grids; 2-column form grid; 3-per-row option tiles; dashboard sidebar; 3-column footer
Desktop≥ 1024px1440 × 900Multi column2-column hero with preview; 4-column card grids; 3-column wizard (steps / question / summary); sticky sidebars; 4-column footer
Fluid layout

Container width: 92%; max-width: 1200px. Grids use fr units; no fixed pixel widths on content.

Flexible images

max-width: 100%; height: auto globally; card imagery locked to aspect-ratio: 4/3 so rows align at any width.

Media queries

@media (min-width: 768px) and (min-width: 1024px) only. Layout changes, never content removal.

6. Iconography

A single stroke-based set (2px, round caps) so UI icons and pest glyphs share one visual weight. Pest glyphs are deliberately schematic — recognisable silhouettes rather than realistic drawings — to reduce squeamishness and stay legible at 28px.

7. Accessibility rules

Touch targets ≥ 44px

Buttons 48px, nav items and menu button 44px, option tiles 96px — comfortably above the WCAG 2.2 (2.5.8) minimum of 24×24px.

Contrast

Body text 12.6:1, secondary text 5.4:1, white on Green 700 6.9:1, Green 900 on Amber 500 7.1:1 — all pass AA; body passes AAA.

Labels & errors

Visible labels on every field; errors combine colour, an icon and text so colour is never the only cue.

Focus & keyboard

4px focus ring on inputs; buttons are real <button> elements; menu button exposes aria-expanded.
